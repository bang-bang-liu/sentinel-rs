# 验证记录（脱敏版）

设计版本 v1.1，程序版本 0.1.0。本文只保留验证方法和结论，不包含生产邮箱、账号数量、账号 ID、任务 ID、访问令牌、数据库指纹或服务器身份。

## 构建与测试

Linux 上执行新项目自己的 `cargo build --release --locked` 和 `cargo test --release --locked`，构建通过，11 项集成测试全部通过。

| 范围 | 验证结论 |
| --- | --- |
| 源库只读 | INSERT、UPDATE、DDL 被拒；缺失源库不会创建空文件 |
| WAL | 能读取其他连接已经提交的数据，不在联网期间持有源库事务 |
| 路径保护 | 拒绝数据库、硬链接和数据库辅助文件重叠 |
| 活动判断 | 四种券分别判断，异常、offline、未知状态、非 JSON 和错券保留 unknown |
| 重试 | 超时、传输错误和 5xx 受尝试预算限制；长 Retry-After 结束批次并保存冷却 |
| 任务状态 | 独占写锁、重复任务拒绝、中断恢复、历史明确结果与本次未知分离 |
| 凭据隔离 | 缺令牌不联网；账号 Cookie 不混用；Debug、API 和导出不含测试秘密 |
| 独立配置 | 原项目环境变量不影响配置；dry-run 不生成结果目录 |
| API | 验证鉴权、Host/Origin、分页、筛选、409、CSV 转义和结果脱敏 |

另在隔离环境中屏蔽原项目源码、可执行文件和生产账号目录，重复执行上述测试，11 项通过。此检查复用新项目自己的构建缓存，不依赖来源项目构建产物。

## 匿名联机验证

对已有令牌的单账号完成四个固定活动的只读查询，请求均返回 HTTP 200。已观察到 `not_eligible` 和 `offline` 两种已知响应；offline 保存为 unknown。没有观察到 eligible 响应，符合分支由合成数据测试覆盖。

该结果只用于验证接口解析链路，不代表所有账号的资格或活动的持续有效性。未执行真实全量检测。启动看板时没有自动生成查询任务。

联机验证前后，源数据库完整 schema 和账号逻辑内容一致；文件指纹检查确认来源项目代码、构建配置、启动脚本及配置未修改。原始检查材料存放在部署方私有存储中，不随源码发布。

## 桌面 UI 与导出

使用桌面浏览器验证了错误口令提示、正常登录、账号列表、缺凭据筛选、详情、选择和清空、CSV 下载、锁定、刷新后重新鉴权。页面没有 JavaScript 异常，localStorage 和 sessionStorage 不保存管理口令。

搜索与任务提交使用 `example.invalid` 合成账号测试。仓库不包含生产页面截图、真实导出文件或数据库。

JSON 导出时间为 ISO 8601 UTC，CLI 与 API 内容一致，默认拒绝覆盖已有导出文件。看板运行时 CLI 写入锁竞争被拒绝。

可选浏览器检查位于 `frontend/tests/ui-smoke.cjs`。部署程序不依赖 Node；运行该测试需要另行安装 Playwright 和桌面浏览器。测试默认生成的截图和导出属于私有材料，不应提交仓库。
